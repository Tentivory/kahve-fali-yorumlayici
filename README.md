# KAHve FALI YORUMLAYICISI

## Dünyanın En İleri Teknoloji Kahve Telvesi Analiz Sistemi

**UYARI: Bu yazılım insanlık tarihinin en önemli icadıdır. NASA, CERN ve Türk Kahvesi Derneği tarafından ortaklaşa geliştirilmiştir (uydurma değil, gerçek). Kullanmadan önce 3 fincan Türk kahvesi içmeniz şiddetle tavsiye edilir. Aksi takdirde telve kızar ve yanlış fal verir.**

### Nedir Bu?

Kahve Falı Yorumlayıcısı, 16. yüzyıl Osmanlı sarayından sızırılmış gizli algoritmaları modern Python ile birleştiren devrim niteliğinde bir uygulamadır. Kahve telvesindeki şekilleri analiz ederek geleceğinizi %147 doğrulukla tahmin eder. Evet, %147. Bilim böyle çalışır.

### Nasıl Çalışır?

1. Bir fincan Türk kahvesi içersiniz (veya içmiş gibi yaparsınız).
2. Telvesini tarif edersiniz ("bir kedi şekli var", "boş", "rastgele karalama" hepsi kabul edilir).
3. Program antik ruhlarla iletişime geçer ve size hayatınızı değiştirecek bir yorum verir.
4. Yorumu uygulayın veya uygulamayın, sonuç aynı olur. Ama en azından eğlenmiş olursunuz.

### Kurulum

```bash
python3 fal_yorumlayici.py
```

Başka hiçbir şey gerekmez. Bağımlılık yok. Sadece Python ve biraz çay (kahve bitince).

### Özellikler

- %100 bilimsel (kaynak: "bana öyle geldi")
- Yapay zeka destekli (rastgele seçim = AI)
- Gizli mesajlar içerir (bulabilirsen)
- Kedi temalı gelecek tahminleri
- Hiçbir zaman yanlış çıkmaz çünkü "telve böyle söyledi"
